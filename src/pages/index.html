A website, a web app, a PWA and a native app are different things

They get mixed up all the time. Knowing which one you need is the first decision, and it affects cost, reach and what the app can do.

Mostly for reading

Website

Pages of information about you or your organisation. Visitors read, browse and get in touch.

What I build

Web application

Software that runs in the browser. People log in, enter data, book, manage and get things done.

Optional extra

Progressive Web App

A web app that supported browsers can add to a home screen or desktop, with features like offline access built in where they’re needed.

Sometimes the right call

Native app

Built separately for iPhone, Android and other platforms and installed from an app store. Gives the deepest access to device hardware.

Why build for the browser

For most business, club and organisation software, a well-built web app does the job without separate versions for each device.

  • One app, many devicesThe same app works on Android and iPhone, iPad, Windows and Mac through a modern browser.
  • Open it with a web addressNo compulsory app-store download. Share a link and people can start using it.
  • Updates in one placeWhen something changes, I update the app on the server and everyone gets the new version.
  • Built around your workflowBespoke screens, rules and processes, instead of bending your work to fit off-the-shelf software.
  • Secure accountsLogins, roles and permissions where you need them, so people only see what they should.
  • Your data, organisedA proper database behind the app, with search, filtering, exports and reports.
  • Connected to your other toolsIntegrations with payments, email, calendars and other services that offer an API.
  • Installable where it helpsAs a PWA, the app can be added to the home screen or desktop on supported devices and browsers.
  • Support after launchOngoing fixes, improvements and new features as your needs change.

When a web app isn’t the answer

Some apps need things browsers can’t do consistently: heavy 3D games, continuous background tracking, or deep access to Bluetooth, NFC and other hardware, especially on iPhone. Some businesses also need a listing in the App Store or Google Play.

If that’s you, I’ll say so at the start rather than build the wrong thing. See when native development makes more sense.
