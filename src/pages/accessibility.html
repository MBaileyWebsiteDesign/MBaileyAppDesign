Accessibility statement

This website aims to be usable by as many people as possible. Last updated November 2026.

What this site aims for

The site is designed to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA. You should be able to:

  • Use every page and form with a keyboard alone, with a clearly visible focus outline.
  • Use the site with a screen reader. Pages use proper headings, landmarks and labelled form fields.
  • Zoom text up to 400% without content being cut off.
  • Read text with sufficient contrast against its background.
  • Turn off non-essential animation using your device’s “reduce motion” setting.

Known limitations

The animated example app on the home page is decorative and is described in text for screen readers. If you find any part of the site hard to use, please let us know.
